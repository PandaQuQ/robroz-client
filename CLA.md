## How to sign

The copyright holder, PandaQuQ, and commits authored under the PandaQuQ account are not required to sign this agreement.

1. Open your pull request against <https://github.com/PandaQuQ/robroz>.
2. Add this line to the pull request description, using your GitHub username:

   ```text
   I have read the robroz CLA (CLA.md) and I agree to its terms. — @your-github-username
   ```

   If the pull request template has a CLA checkbox, ticking it means the same thing.
3. Submitting a pull request with that line or that ticked box is your signature. The pull request (and its history on GitHub) is the record.
